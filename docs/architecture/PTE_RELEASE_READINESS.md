# PTE 商业上线验收

当前结论：**不可作为商业服务正式开放或收费**。练习工作台可供开发验证，但通过构建、模拟浏览器测试或依赖审计，都不等于生产认证。

本清单以当前源代码为依据，只有提供对应环境中的验证证据后才能关闭事项。不能以演示数据、前端隐藏按钮或本地身份代替服务端权限。

## 上线阻断项

| 项目 | 当前事实 | 验收要求 |
| --- | --- | --- |
| 产品与数据隔离 | PTE 与私人情侣网站共用 Next.js 外壳、Supabase 客户端和本地身份 | 确认独立站方案；独立环境、数据边界及域名，不向付费用户暴露私人功能或数据 |
| 真实认证 | `hooks/useAuth.ts` 读取浏览器身份，不验证用户凭证 | 注册、邮箱验证、登录、重置密码、注销及会话撤销；服务端验证每次受保护请求 |
| 数据授权 | PTE 仓储按客户端传来的 user_id 查询，历史策略并非可信授权 | 以真实 auth uid 实施 RLS；匿名、越权、跨用户读写及 Storage 签名访问的负向测试 |
| 评分滥用 | 两个 Next.js 评分代理没有用户级权限、共享限流或配额 | 服务端身份校验、分布式限流、每用户额度、并发上限、超时与成本告警；越权不得调用模型 |
| 成绩与题库完整性 | 客户端包含答案与本地计分，并可直接提交练习记录 | 收费题目由服务端授权发放；正式成绩服务端计算与保存，不信任客户端传入的分数或会员状态 |
| 支付与权益 | 尚无正式商品、支付回调及权益账本 | 明确市场/币种/支付供应商；验签、幂等、退款撤权、失败重试及对账通过沙箱验收 |
| 内容授权 | 内置原创练习不能证明第三方上传内容有商业授权 | 每批题库/音频的来源、权利范围、版本和审核记录；用户上传隔离审核；不抓取竞品付费题库 |
| 题型覆盖 | 已支持 22 种题型（含 SGD、RTS）；SGD 内置讨论约 1 分钟，短于真实考试，两者的发音维度暂不评估 | 补全目标考试题型或准确限定产品范围；模考题量、计时与评分规格逐项核对 |
| 评分质量 | 主观反馈含启发式估算，默认音频为浏览器 TTS | 明确非官方评分；真人盲评样本集、误差分析及降级验证；真实设备录音和生产模型端到端测试 |
| 运行保障 | 未完成生产环境容量、故障恢复及备份演练 | 监控与告警、容量/成本预算、备份恢复、灰度与回滚、客服处理流程 |
| 隐私与条款 | 未确定运营主体、地区和数据保留规则 | 结合目标市场完成专业审核；录音告知、处理商清单、保留/删除/导出机制与投诉渠道 |
| 容器供应链 | 模型镜像/权重及 Python 依赖需要独立检查 | 锁定镜像与模型版本，核验商业许可证并审计容器；npm 审计不覆盖这一层 |

## 已建立的检查

- `npm run check`：仓库 ESLint、TypeScript 和 Next.js 生产构建。
- `npm audit`：Node 依赖审计，不能替代权限审查或 Python/容器审计。
- `node scripts/test-pte-practice.mjs`：练习默认答案、排序相邻对、分数边界及未评估结果过滤。
- `node scripts/test-pte-api.mjs`：流式请求体大小/超时、重复字段、上游响应结构与分数范围；替换网络调用，不连接实际评分服务。
- `node scripts/test-pte-browser.mjs`：隔离身份及网络请求，验证提交/重练/录音收尾、播放暂停、模考退出提醒、移动端溢出；录音和语音使用替身，不验证真实设备或模型质量。
- `python -m unittest discover -s pte-scoring-service/gateway -p "test_*.py"`：评分网关认证、输入长度、下游故障及正常结果；仅使用模拟下游。

浏览器脚本需要本机 Edge 和 Playwright，可用 `PLAYWRIGHT_MODULE` 指向独立测试环境中的 Playwright 模块目录，`PTE_TEST_URL` 指定本地地址（默认 `http://localhost:3100`）。截图保存在操作系统临时目录，不写入生产数据。

## 人工环境操作

1. 确认独立站、账号体系、支付市场和题库授权。不要在聊天中提供真实密钥。
2. 为商业环境建立独立 Supabase 项目和部署项目。完成审核后的迁移由负责人手动执行，不能直接复用私人站点的宽松策略。
3. 在 Secret 管理界面配置服务凭证。评分容器必须提供 `SHARED_TOKEN`，模型端口仅内部可达，网关仅监听本机，由 HTTPS 反向代理转发。
4. 支付商户审核、生产回调、数据处理及内容授权文件完成后，进行生产等价环境的验收。
5. 验收人确认所有阻断项关闭后，另行授权发布。当前工作不包含线上部署或数据库执行。
